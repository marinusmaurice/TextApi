Decorations

Decorations attach metadata to character ranges — squiggles, syntax highlights, search highlights, bookmarks, and custom data. They automatically track text edits: an insert before a decoration shifts its offsets; a delete that encompasses the decoration removes it.

Quick Reference

using TextAPI.Core.Decorations;

// Add an error squiggle on chars 10–20
Guid id = doc.AddDecoration(start: 10, end: 20, DecorationType.ErrorSquiggle, tag: "CS0101");

// Remove it later
doc.RemoveDecoration(id);

// Query decorations overlapping a range
foreach (var d in doc.GetDecorationsInRange(0, 100))
    Console.WriteLine($"{d.Type} [{d.Start},{d.End}) tag={d.Tag}");

DecorationTree (Direct Access)

For bulk operations, use the underlying DecorationTree directly:

using TextAPI.Core.Decorations;

// Access the tree (internal to TextDocument)
var tree = doc.Decorations;

// Add
tree.AddDecoration(new Decoration
{
    Id    = Guid.NewGuid(),
    Start = 0,
    End   = 50,
    Type  = DecorationType.Custom,
    Tag   = "my-tag",
    Data  = myPayload
});

// Remove all error squiggles
tree.RemoveAllOfType(DecorationType.ErrorSquiggle);

// Clear everything
tree.Clear();

// Count
Console.WriteLine(tree.Count);

// Query by line range
int lineStart = doc.PositionToOffset(5, 0);
int lineEnd   = doc.PositionToOffset(5, doc.GetLine(5).Length);
var lineDecos = tree.GetDecorationsOnLine(lineStart, lineEnd);

Automatic Offset Tracking

When text is inserted or deleted, all decoration offsets are adjusted automatically:

// Decoration at [10, 20)
Guid id = doc.AddDecoration(10, 20, DecorationType.Bookmark);

// Insert 5 chars before the decoration
doc.Insert(5, "HELLO");

// Decoration has automatically shifted to [15, 25)
var d = doc.GetDecorationsInRange(0, doc.Length).First(x => x.Id == id);
Console.WriteLine($"{d.Start}–{d.End}"); // 15–25

// Delete text that completely contains the decoration → decoration is removed
doc.Delete(14, 12);  // deletes [14, 26) which covers [15, 25)
// decoration is gone — no stale references

Example: Diagnostics Overlay

// Clear old diagnostics and apply new ones from a language server
tree.RemoveAllOfType(DecorationType.ErrorSquiggle);
tree.RemoveAllOfType(DecorationType.WarningSquiggle);

foreach (var diag in diagnostics)
{
    var type = diag.Severity == "error"
        ? DecorationType.ErrorSquiggle
        : DecorationType.WarningSquiggle;

    doc.AddDecoration(
        start: doc.PositionToOffset(diag.Line, diag.Col),
        end:   doc.PositionToOffset(diag.Line, diag.EndCol),
        type:  type,
        tag:   diag.Code,
        data:  diag
    );
}

// Highlight all matches for the current search term
