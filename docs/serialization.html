JSON Serialization

OperationMapper serializes and deserializes operations to and from JSON. This is the bridge between external systems (LLMs, APIs, config files) and the TextAPI execution engine.

JSON Format Rules

  • Every operation object must have a "type" field with the operation's type string (e.g. "REPLACE_ALL").
  • All other property names are camelCase (e.g. caseSensitive, not CaseSensitive).
  • Type string matching is case-sensitive and must be exact.
  • Unknown fields are silently ignored.
  • Missing optional fields use their defaults.

Two JSON Formats

Bare Array

A JSON array of operation objects:

[
  { "type": "REPLACE_ALL", "find": "foo", "replace": "bar" },
  { "type": "TRIM_TRAILING_WHITESPACE" },
  { "type": "SORT_LINES", "descending": true }
]

Pipeline Object

A JSON object with an "operations" array (useful when you want to add pipeline-level metadata later):

{
  "operations": [
    { "type": "REPLACE_ALL", "find": "foo", "replace": "bar" },
    { "type": "TRIM_TRAILING_WHITESPACE" }
  ]
}

OperationMapper API

MethodDescription
FromJson(string json)Parse a bare array. Returns IReadOnlyList<IDocumentOperation>. Throws JsonException if root is not an array or a type is unknown.
FromPipelineJson(string json)Parse a pipeline object ({"operations":[...]}). Throws JsonException if the key is missing.
ToJson(IDocumentOperation op)Serialize one operation to a JSON object string.
ToPipelineJson(IEnumerable<IDocumentOperation> ops)Serialize a list of operations to a pipeline object string.

Deserializing

using TextAPI.Operations.Serialization;

// Bare array
var ops = OperationMapper.FromJson("""
[
  {"type":"REPLACE_ALL","find":"TODO","replace":"DONE"},
  {"type":"SORT_LINES"}
]
""");

// Pipeline object
var ops2 = OperationMapper.FromPipelineJson(jsonString);

// Run them
var result = new DocumentPipeline(doc).Add(ops).Execute();

Serializing

// Single op
var op   = new ReplaceAllOperation { Find = "a", Replace = "b", CaseSensitive = false };
string json = OperationMapper.ToJson(op);
// {"type":"REPLACE_ALL","find":"a","replace":"b","caseSensitive":false,"wholeWord":false}

// List of ops as pipeline JSON
IDocumentOperation[] ops = [
    new AppendOperation  { Text = " World" },
    new PrependOperation { Text = "Hello" }
];
string pipeline = OperationMapper.ToPipelineJson(ops);

Complete JSON Examples — All Operations

Offset-Based

{ "type": "INSERT_AT",  "offset": 10, "text": "hello" }
{ "type": "DELETE_AT",  "offset": 0,  "length": 5 }
{ "type": "REPLACE_AT", "offset": 6,  "deleteLength": 5, "text": "World" }

Anchor-Based

{ "type": "INSERT_AFTER",   "anchor": "Section 1", "text": "\nnew content", "occurrence": 1 }
{ "type": "INSERT_BEFORE",  "anchor": "## End",     "text": "footer\n" }
{ "type": "APPEND",         "text": "\n// EOF" }
{ "type": "PREPEND",        "text": "// Copyright\n" }
{ "type": "REPLACE_SECTION", "startAnchor": "/* B */", "endAnchor": "/* E */", "text": "new", "includeAnchors": false }
{ "type": "DELETE_SECTION",  "startAnchor": "/* B */", "endAnchor": "/* E */", "includeAnchors": true }

Pattern-Based

{ "type": "REPLACE_ALL",  "find": "foo", "replace": "bar", "caseSensitive": true, "wholeWord": false }
{ "type": "REGEX_REPLACE", "pattern": "\\d{4}", "replacement": "XXXX" }

Line-Based

{ "type": "INSERT_LINE",            "lineIndex": 3, "text": "new line" }
{ "type": "DELETE_LINE",            "lineIndex": 2 }
{ "type": "REPLACE_LINE",           "lineIndex": 0, "text": "replacement" }
{ "type": "INSERT_AFTER_LINE_MATCH", "pattern": "def main", "lineText": "    pass", "occurrence": 1 }

Transform

{ "type": "NORMALISE_WHITESPACE" }
{ "type": "TRIM_TRAILING_WHITESPACE" }
{ "type": "CONVERT_CASE", "mode": "upper" }
{ "type": "CONVERT_CASE", "mode": "titleCase", "startAnchor": "## Name", "endAnchor": "##" }
{ "type": "SORT_LINES",    "descending": false, "caseSensitive": true }
{ "type": "DEDUPLICATE_LINES", "consecutiveOnly": false }
{ "type": "INDENT",         "startLine": 2, "endLine": 5, "prefix": "  ", "dedent": false }
{ "type": "WRAP_LINES",     "maxColumns": 80 }

Query

{ "type": "FIND_ALL",        "pattern": "TODO", "useRegex": false, "caseSensitive": true }
{ "type": "EXTRACT_SECTION", "startAnchor": "<!-- s -->", "endAnchor": "<!-- e -->", "includeAnchors": false }
{ "type": "CONTAINS",        "pattern": "DRAFT", "useRegex": false }

Structural

{ "type": "MOVE_SECTION",   "sourceStartAnchor": "[S]", "sourceEndAnchor": "[E]", "destinationAnchor": "[DEST]", "insertAfterDestination": true }
{ "type": "SWAP_SECTIONS",  "section1Start": "[A]", "section1End": "[B]", "section2Start": "[C]", "section2End": "[D]" }

Error Handling

try
{
    var ops = OperationMapper.FromJson(json);
}
catch (JsonException ex)
{
    // Possible causes:
    // - Root is not an array
    // - "type" field is missing
    // - Unknown type string
    Console.WriteLine(ex.Message);
}

LLM Integration Pattern

// Typical flow when an LLM produces edit instructions:
string llmOutput = await GetLlmResponseAsync(prompt);

IReadOnlyList<IDocumentOperation> ops;
try   { ops = OperationMapper.FromPipelineJson(llmOutput); }
catch { /* malformed JSON — ask LLM to retry */ return; }

var result = new DocumentPipeline(doc).Add(ops).Execute();
if (!result.Success)
{
    // Tell the LLM what went wrong and which operation failed
    string feedback = $"Operation #{result.FailedOperationIndex} failed: {result.ErrorMessage}";
}
