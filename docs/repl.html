C# REPL

CSharpScriptHost provides an interactive, stateful C# scripting environment backed by Roslyn. Variables declared in one call remain in scope for subsequent calls. The document and cursor are always available as doc and mc.

Setup

using TextAPI.Repl;
using TextAPI.Core.Cursor;

var doc  = new TextDocument();
var mc   = new MultiCursor(doc);
var host = new CSharpScriptHost(doc, mc);

Executing Code

// Submissions are stateful — variables persist across calls
var r1 = await host.ExecuteAsync("var n = doc.LineCount;");
var r2 = await host.ExecuteAsync("Print(n);");  // n is still in scope

Console.WriteLine(r2.Output);       // "42"
Console.WriteLine(r2.Success);      // true

CSharpScriptHost API

MemberTypeDescription
ExecuteAsync(code, ct?)Task<ScriptExecutionResult>Compile and run a C# submission. State persists.
Reset()voidClear all session state — variables, using aliases, etc.
HasStateboolTrue once at least one submission has been executed.

ScriptExecutionResult

PropertyTypeDescription
SuccessboolTrue if compilation and execution succeeded.
OutputstringEverything written via Print(), joined by newlines.
ReturnValueobject?The value of the last expression (if any).
ErrorMessagestring?Compiler or runtime error message.
ExceptionException?The runtime exception, if one was thrown.

Built-in Globals

These identifiers are always in scope — no import needed:

NameTypeDescription
docTextDocumentThe active document. All edits, searches, and saves go through here.
mcMultiCursorThe multi-cursor bound to doc.
Print(value?)voidWrite to REPL output. Accepts any object; null prints a blank line.
print(value?)voidLowercase alias for Print.
NewPipeline()DocumentPipelineCreate a fresh pipeline bound to doc.
RunJson(json)PipelineResultParse a JSON pipeline and execute it in one call.
ParseOps(json)IReadOnlyList<IDocumentOperation>Deserialize JSON operations without executing.

Working with the Document

// Load content
await host.ExecuteAsync("""doc.Load("Hello World\nLine 2\nLine 3");""");

// Query
var r = await host.ExecuteAsync("""
    Print(doc.LineCount);
    Print(doc.Length);
    Print(doc.GetLine(0));
""");
// r.Output == "3\n13\nHello World"

// Edit
await host.ExecuteAsync("""doc.Insert(0, "// Header\n");""");
await host.ExecuteAsync("""doc.ReplaceAll("World", "TextAPI");""");

Using the Pipeline from the REPL

// Fluent pipeline
var r = await host.ExecuteAsync("""
    var result = NewPipeline()
        .Add(new ReplaceAllOperation { Find = "foo", Replace = "bar" })
        .Add(new TrimTrailingWhitespaceOperation())
        .Execute();
    Print(result.AuditLog.Summary);
""");

// JSON pipeline shortcut
await host.ExecuteAsync("""
    var pr = RunJson(@"{
      ""operations"": [
        { ""type"": ""REPLACE_ALL"", ""find"": ""TODO"", ""replace"": ""DONE"" }
      ]
    }");
    Print(pr.Success);
""");

Persistent State Across Submissions

// Submission 1 — declare a helper
await host.ExecuteAsync("""
    int CountWord(string w) => doc.CountMatches(w);
""");

// Submission 2 — use it (still in scope)
var r = await host.ExecuteAsync("""
    Print(CountWord("TODO"));
    Print(CountWord("FIXME"));
""");

// Reset everything
host.Reset();
Console.WriteLine(host.HasState); // false

Cancellation

using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
var result = await host.ExecuteAsync(longRunningCode, cts.Token);

if (!result.Success)
    Console.WriteLine(result.ErrorMessage); // "The operation was canceled."

Error Handling

var r = await host.ExecuteAsync("throw new InvalidOperationException(\"oops\");");

Console.WriteLine(r.Success);        // false
Console.WriteLine(r.ErrorMessage);  // "oops"
Console.WriteLine(r.Exception?.GetType().Name); // "InvalidOperationException"

// State is preserved after an exception — you can keep going
Console.WriteLine(host.HasState); // true

Complete Interactive Session Example

var doc  = new TextDocument();
var mc   = new MultiCursor(doc);
var host = new CSharpScriptHost(doc, mc);

await doc.LoadFileAsync("contract.txt");

// Step 1 — inspect
var r = await host.ExecuteAsync("""
    Print($"Lines: {doc.LineCount}");
    Print($"TODOs: {doc.CountMatches("TODO")}");
""");
Console.Write(r.Output);

// Step 2 — fix up
await host.ExecuteAsync("""
    var result = NewPipeline()
        .Add(new ReplaceAllOperation { Find = "DRAFT", Replace = "FINAL" })
        .Add(new TrimTrailingWhitespaceOperation())
        .Execute();
    Print(result.AuditLog.Summary);
""");

// Step 3 — save
await host.ExecuteAsync("""await doc.SaveFileAsync();""");
