Encoding & EOL

TextAPI automatically detects encoding (BOM, UTF-8, Windows-1252, Latin-1) and EOL style (LF, CRLF, CR) when loading a file. By default it round-trips both exactly — no silent conversions unless you ask for them.

Loading Files

// Auto-detect encoding and EOL
await doc.LoadFileAsync("/path/to/file.txt");

// Override encoding (skip auto-detection)
await doc.LoadFileAsync("/path/to/file.txt", encoding: System.Text.Encoding.Latin1);

BOM Detection Order

The detector checks byte sequences in this priority order:

  1. 00 00 FE FF → UTF-32 BE
  2. FF FE 00 00 → UTF-32 LE
  3. EF BB BF → UTF-8 with BOM
  4. FE FF → UTF-16 BE
  5. FF FE → UTF-16 LE

Heuristic Detection (No BOM)

  1. All bytes 0x00–0x7F → UTF-8 (Fallback)
  2. Valid UTF-8 multi-byte sequences → UTF-8 (HighConfidence)
  3. Bytes in 0x80–0x9F → Windows-1252 (Heuristic)
  4. Only bytes in 0xA0–0xFF → Latin-1 (Heuristic)

Saving with Encoding Control

// Default — preserve original encoding and EOL
await doc.SaveFileAsync();

// Override for this save only
doc.SaveEncoding = System.Text.Encoding.UTF8;
await doc.SaveFileAsync();

// Convert EOL to CRLF on save (Windows style)
doc.SaveEolStyle = EolStyle.CRLF;
await doc.SaveFileAsync();

// Save to stream (to memory, network, etc.)
await doc.SaveAsync(stream);

Internal Representation

Internally the document always stores text with LF (\n) as the line separator. GetText() returns normalised LF. GetTextWithEol() converts back to the document's SaveEolStyle:

string internal_ = doc.GetText();        // always LF
string forSave   = doc.GetTextWithEol();  // uses SaveEolStyle

Detecting Encoding at Runtime

Use EncodingDetector directly when you need to probe a file without loading a document:

using TextAPI.Core.Encoding;

using var stream = File.OpenRead("mystery.txt");
DetectedEncoding detected = EncodingDetector.Detect(stream);

Console.WriteLine(detected.Encoding.WebName); // e.g. "utf-8"
Console.WriteLine(detected.Confidence);        // e.g. HighConfidence
Console.WriteLine(detected.HasBom);            // true/false

Writing BOMs

using TextAPI.Core.Encoding;

// Write BOM preamble to a stream before writing text bytes
BomWriter.WriteBom(outputStream, doc.DetectedEncoding!);

Round-Trip Example

// Load a Windows CRLF file with UTF-16 LE BOM
await doc.LoadFileAsync("windows-file.txt");

Console.WriteLine(doc.DetectedEncoding?.Encoding.WebName); // "utf-16"
Console.WriteLine(doc.OriginalEolStyle);                   // CRLF
Console.WriteLine(doc.HasBom);                              // true

// Make an edit
doc.ReplaceAll("TODO", "DONE");

// Save — preserves UTF-16 LE BOM and CRLF automatically
await doc.SaveFileAsync();
