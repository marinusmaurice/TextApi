Script DSL

ScriptRunner executes a line-oriented command language directly on a TextDocument. No compilation step — paste a block of text, call Run(), get a result. Great for batch processing, macros, and AI-generated edits.

Basic Usage

using TextAPI.Core.Scripting;

var runner = new ScriptRunner(doc);

ScriptResult result = runner.Run("""
    REPLACE_ALL "TODO" "DONE"
    INSERT_AT 0 "// Auto-generated\n"
    DELETE_LINE 1
    GOTO 3 0
    INSERT "Hello"
""");

if (!result.Success)
    Console.WriteLine($"Error at line {result.ErrorLine}: {result.ErrorMessage}");

All Commands

Cursor Movement

CommandDescription
MOVE <offset>Move cursor to absolute character offset.
GOTO <line> [<col>]Move to 1-based line, optional 0-based column (default 0).
SELECT <start> <end>Set cursor selection from start offset to end offset.

Insertion & Deletion

CommandDescription
INSERT "<text>"Insert text at the current cursor position.
INSERT_AT <offset> "<text>"Insert text at an explicit offset.
DELETE <n>Delete n characters at the cursor.
DELETE_AT <offset> <n>Delete n characters at an explicit offset.
DELETE_LINE [<line>]Delete 1-based line number. Defaults to the cursor's current line.

Find & Replace

CommandDescription
REPLACE_ALL "<pat>" "<rep>" [flags]Replace all occurrences. Updates LastReplaceCount.
FIND "<pat>" [flags]Move cursor to the next match after the current offset.
FIND_PREV "<pat>" [flags]Move cursor to the previous match before the current offset.
FIND_ALL "<pat>" [flags]Collect all matches into LastFindAll. Cursor does not move.

Search Flags

FlagMeaning
/iCase-insensitive match.
/wWhole-word match.
/rPattern is a regular expression.
 
FIND "TODO" /i          # find next, case-insensitive
FIND_ALL "\bTODO\b" /r  # find all whole-word TODOs via regex
REPLACE_ALL "foo" "bar" /i /r

Undo / Redo

UNDO   # undo one step
REDO   # redo one step

Miscellaneous

NOP    # no-operation, useful as a placeholder

String Literals

All string arguments are double-quoted. Standard escape sequences are supported:

EscapeCharacter
\nNewline (LF)
\rCarriage return
\tTab
\\Backslash
\"Double quote
 
INSERT "line 1\nline 2\n"
INSERT_AT 0 "// Header\n"

ScriptResult

PropertyTypeDescription
SuccessboolTrue if every command executed without error.
StepsExecutedintNumber of commands executed (including the failing one).
StepsIReadOnlyList<StepResult>Per-step results.
ErrorMessagestring?Non-null when Success is false.
ErrorLineint?1-based script line number of the failing command.
CursorOffsetintCursor offset at the end of execution.
LastReplaceCountintNumber of replacements made by the last REPLACE_ALL.
LastFindAllIReadOnlyList<SearchMatch>Matches from the last FIND_ALL.

StepResult

PropertyTypeDescription
LineNumberintScript line number (1-based).
VerbstringCommand verb (e.g. "REPLACE_ALL").
SuccessboolWhether this step succeeded.
CursorAfterintCursor offset after this step.
ErrorMessagestring?Error detail if failed.

Pre-Parsed Execution

Parse once, execute many times:

var commands = ScriptParser.Parse(scriptText);  // IReadOnlyList<ScriptCommand>

// Re-run on different documents without re-parsing
foreach (var doc in documents)
{
    var runner = new ScriptRunner(doc);
    var result  = runner.Execute(commands);
}

Cursor State

The runner maintains a single cursor whose position is updated by each command. Read it between runs:

var runner = new ScriptRunner(doc);
runner.Run("GOTO 5 0");
Console.WriteLine(runner.CursorOffset); // offset of line 5, col 0

Error Handling

Execution stops at the first failing command. The document state at that point is whatever the successful commands produced — there is no automatic rollback. If you need atomic execution, use DocumentPipeline instead.

var result = runner.Run(script);
if (!result.Success)
{
    Console.WriteLine($"Failed on line {result.ErrorLine}: {result.ErrorMessage}");
    // Inspect which steps ran successfully
    foreach (var step in result.Steps)
        Console.WriteLine($"  [{step.LineNumber}] {step.Verb}: {(step.Success ? "ok" : step.ErrorMessage)}");
}

Complete Example: Normalize a Source File

var runner = new ScriptRunner(doc);
var result = runner.Run("""
    REPLACE_ALL "  " "    "        # expand 2-space indent to 4
    REPLACE_ALL "\t" "    "        # expand tabs
    REPLACE_ALL "\r\n" "\n"        # normalise line endings
    INSERT_AT 0 "// DO NOT EDIT\n"
    FIND_ALL "TODO" /i
""");

Console.WriteLine($"TODOs remaining: {result.LastFindAll.Count}");
