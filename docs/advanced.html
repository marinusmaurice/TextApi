Advanced Features

TextAPI ships a suite of editor-level feature models: folding, bookmarks, inlay hints, sticky scroll, snippets, outline, word wrap, change tracking, and read-only regions. Each model is independent and connects to the document through explicit calls.

Folding

FoldingModel detects and manages collapsible regions. Any strategy implementing IFoldingStrategy can supply regions; BraceFoldingStrategy is provided out of the box.

using TextAPI.Core.Folding;

var model = new FoldingModel();
model.UpdateRegions(new BraceFoldingStrategy(), doc);

// Fold / unfold
model.ToggleFold(startLine: 5);
model.FoldAll();
model.UnfoldAll();

// Query
Console.WriteLine(model.VisibleLineCount);
bool visible = model.IsLineVisible(7);

// Map between display and document lines
int docLine     = model.ToDocumentLine(displayRow: 3);
int displayRow  = model.ToDisplayLine(docLine: 10);

// Get only the lines that are visible (for rendering)
int[] visibleLines = model.GetVisibleLines();

// React to changes
model.FoldStateChanged += (s, e) => Redraw();
model.RegionsChanged   += (s, e) => RefreshGutter();

Bookmarks

BookmarkModel tracks a set of bookmarked line numbers. Bookmarks automatically remap when lines are inserted or deleted.

using TextAPI.Core.Navigation;

var bookmarks = new BookmarkModel();

// Toggle bookmark on line 5
bool added = bookmarks.Toggle(5);  // true = now bookmarked

// Navigate
int? next = bookmarks.NextBookmark(fromLine: cursor.CaretLine);
int? prev = bookmarks.PrevBookmark(fromLine: cursor.CaretLine);

if (next is not null)
    cursor.MoveTo(doc.PositionToOffset(next.Value, 0));

// List all
foreach (int line in bookmarks.GetAll())
    Console.WriteLine($"Bookmark at line {line}");

// Hook up offset remapping after document edits
// (call these from your document-edit event handlers)
bookmarks.OnInsert(atLine: 3, count: 2);
bookmarks.OnDelete(atLine: 3, count: 1);

// Listen for changes
bookmarks.BookmarksChanged += (s, e) => UpdateGutter();

Inlay Hints

Inline annotations shown inside the text (parameter names, inferred types). The model tracks offsets and fires HintsChanged when they shift.

using TextAPI.Core.InlayHints;

var hints = new InlayHintModel();

// Add a parameter name hint
Guid id = hints.AddHint(new InlayHint(
    offset:  42,
    text:    "value:",
    kind:    InlayHintKind.Parameter,
    tooltip: "int value"
));

// Replace all hints at once (from language server response)
hints.SetHints(languageServerHints);

// Query
var visible = hints.GetHintsInRange(viewportStart, viewportEnd);
var types   = hints.GetHintsByKind(InlayHintKind.Type);
var atCaret = hints.GetHintAt(cursor.CaretOffset);

// React
hints.HintsChanged += (s, e) => InvalidateViewport();

InlayHintKind Enum

ValueTypical Use
ParameterParameter name before an argument.
TypeInferred type annotation.
ReturnReturn-value annotation.
OtherAny application-defined hint.

Snippets

SnippetEngine parses VS Code–compatible snippet bodies ($1, $2, $0 exit stop) and manages the interactive tab-stop session.

using TextAPI.Core.Snippets;

// Parse once, reuse many times
Snippet template = SnippetEngine.Parse("for (int $1 = 0; $1 < $2; $1++) {\n    $0\n}");

// Insert at cursor and begin session
SnippetSession session = SnippetEngine.BeginSnippet(doc, template, insertOffset: cursor.CaretOffset);

// Navigate tab stops (Tab key)
TabStop? stop = session.NextTabStop();
if (stop is not null)
{
    cursor.SetSelection(stop.Value.Offset, stop.Value.Offset + stop.Value.Length);
}
else
{
    // Reached exit stop ($0) — session done
    session.Commit();
}

// Update mirrors when user types into a tab stop
session.UpdateTabStop(tabStopIndex: 1, newText: "i");  // all $1 mirrors update

// Shift+Tab
TabStop? prev = session.PrevTabStop();

// Escape — undo insertion
session.Cancel();

Outline

OutlineProvider builds a hierarchical tree of document structure from the FoldingModel. Useful for breadcrumb navigation or a document outline panel.

using TextAPI.Core.Outline;

// Requires an up-to-date FoldingModel
IReadOnlyList<OutlineNode> nodes = OutlineProvider.GetOutline(foldingModel);

void PrintTree(IReadOnlyList<OutlineNode> items, int indent = 0)
{
    foreach (var n in items)
    {
        Console.WriteLine($"{new string(' ', indent * 2)}{n.Label} (line {n.StartLine})");
        PrintTree(n.Children, indent + 1);
    }
}
PrintTree(nodes);

OutlineNode Properties

PropertyTypeDescription
LabelstringHeader text (from FoldRegion.Label).
StartLineintZero-based document line of the header.
EndLineintZero-based document line of the closing boundary.
DepthintNesting depth. 0 = top-level.
ChildrenIReadOnlyList<OutlineNode>Direct children in ascending StartLine order.

Word Wrap

WordWrapModel maps between document line numbers and wrapped display rows using grapheme-cluster-aware column counting. Set ViewportWidth to the number of visible character columns.

using TextAPI.Core.WordWrap;

var wrap = new WordWrapModel(doc, viewportWidth: 80);

// Map line → display row (for rendering at correct y position)
int row = wrap.ToDisplayRow(docLine: 10);

// Map display row → document line (for hit-testing a click)
int line = wrap.ToDocumentLine(displayRow: 15);

// How many rows does line 3 occupy?
int rows = wrap.WrappedRowCount(3);

// Character offset ranges for each visual row of a line
var segments = wrap.GetWrappedSegments(docLine: 3);
foreach (var (start, end) in segments)
    Console.WriteLine($"  row chars [{start}, {end})");

// Resize viewport (e.g. window resize)
wrap.Resize(newWidth: 120);
wrap.WrapChanged += (s, e) => InvalidateViewport();

Console.WriteLine($"Total display rows: {wrap.DisplayRowCount}");

Change Tracking

ChangeTracker computes per-line diff status relative to a saved baseline — the coloured gutter markers ("added", "modified", "deleted") common in modern editors.

using TextAPI.Core.ChangeTracking;

var tracker = new ChangeTracker(doc);

// Capture baseline (e.g. on file save or initial load)
tracker.SetBaseline();

// ... user makes edits ...

// Query per-line status (lazy — diff computed on first access)
LineStatus status = tracker.GetStatus(lineIndex: 5);
// LineStatus.Clean | LineStatus.Added | LineStatus.Modified

// Does this line have deleted lines above it?
bool deletionAbove = tracker.HasDeletionAbove(5);

// Enumerate all changed lines
foreach (var (line, status2) in tracker.ChangedLines())
    Console.WriteLine($"Line {line}: {status2}");

// Where are the deleted-line indicators?
foreach (int point in tracker.DeletionPoints())
    Console.WriteLine($"Deleted lines above line {point}");

// React to changes
tracker.ChangesUpdated += (s, e) => UpdateGutter();

Console.WriteLine(tracker.HasAnyChanges);

LineStatus Enum

ValueGutter ColourMeaning
CleanNoneIdentical to baseline.
AddedGreenLine newly inserted since baseline.
ModifiedYellow/AmberLine exists in baseline but content changed.

Read-Only Regions

Protect offset ranges from mutation. When doc.EnforceReadOnly is true (the default), any edit that overlaps a protected region throws ReadOnlyViolationException.

using TextAPI.Core.ReadOnly;

var regions = new ReadOnlyRegionModel();

// Protect the header (first 100 chars)
Guid id = regions.Protect(start: 0, end: 100);

// Check before editing
if (!regions.IsRangeReadOnly(offset, length))
    doc.Insert(offset, text);

// Remove protection
regions.Unprotect(id);
regions.UnprotectAll();

// Inspect
foreach (var (rid, start, end) in regions.GetRegions())
    Console.WriteLine($"Protected [{start}, {end})");

// Disable enforcement (allow bypassing protection)
doc.EnforceReadOnly = false;

regions.RegionsChanged += (s, e) => UpdateGutter();

Read-only enforcement is controlled by doc.EnforceReadOnly. Set it to false if you need to programmatically edit protected ranges (e.g. during a template expansion).
